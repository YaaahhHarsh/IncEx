## 📌 Version 6.0 (Ultimate Feature Suite Release)
**Folder**: `Versions/Version_6.0_Ultimate_Feature_Suite/`
**ZIP Package**: `KoshWise_v6.0_Final.zip` (In Downloads & Desktop)

### ✨ Features & Changes:
1. **PWA Mobile App Manifest & Service Worker**:
   - Added `manifest.json` and `sw.js` for full offline caching and "Add to Home Screen" app installation on iOS & Android.
2. **OLED Dark Mode Theme Engine**:
   - Integrated OLED Dark Mode toggle with obsidian slate palette and theme persistence.
3. **Voice AI Speech Recognition**:
   - Speak to log transactions (e.g. *"Spent 450 on food"*) using Web Speech API.
4. **Receipt Image Scanner & OCR**:
   - Upload receipt image files to auto-parse amounts and pre-fill transaction notes.
5. **Security PIN Lock Screen**:
   - 4-digit PIN lock overlay protecting privacy on app startup.
